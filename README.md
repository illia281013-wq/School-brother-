# AI School Assistant

Многостраничный учебный сайт для 5–11 классов. Интерфейс — HTML/CSS, интерактивность — JavaScript, серверный AI API — Node.js + Express.

## Возможности
- Главная, предметы, AI-чат, анализ фото, каталог моделей, библиотека и настройки.
- Каталог выбранных семейств открытых моделей через OpenRouter.
- Чат с выбором модели и класса, история в браузере.
- Загрузка JPG/PNG/WEBP до 8 МБ и анализ vision-моделью.
- API-ключ хранится только в серверном .env.

## Запуск
Нужен Node.js 20+.

```bash
npm install
cp .env.example .env
# добавь ключ в OPENROUTER_API_KEY внутри .env
npm run dev
```
Открой http://localhost:5173. Vite проксирует /api на сервер Express (порт 3001).

Production: npm run build, затем задай OPENROUTER_API_KEY и запусти npm start на Node-хостинге.

## Безопасность и данные
Не помещай API-ключ в HTML/JS и не коммить .env. История хранится в localStorage браузера. Изображения передаются OpenRouter для анализа. Supabase не подключён, схема и данные не меняются. Лицензии, цены и лимиты моделей проверяй у провайдера и разработчика модели.

## Проверка
npm test — тесты серверных утилит; npm run build — сборка фронтенда.
