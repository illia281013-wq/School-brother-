# AI School Assistant

Новая версия учебного сайта на чистом **HTML и CSS**. Страница не использует React, JavaScript или клиентскую библиотеку Supabase.

## Запуск
Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Сборка: `npm run build`; предпросмотр: `npm run preview`.

## Структура
- `index.html` — разметка всех разделов сайта.
- `src/styles.css` — оформление и адаптивная вёрстка.
- `vite.config.js` — конфигурация статического сервера и сборки.

## Разделы
Главная, шесть школьных предметов, учебная форма-макет, библиотека формул с раскрывающимися подсказками и план самостоятельной практики.

## Ограничения
Это статический HTML/CSS-сайт. Без JavaScript и серверной части он не выполняет AI-запросы, не проверяет ответы, не регистрирует пользователей и не сохраняет историю. Форма демонстрационная и не передаёт задание на сервер.

## База данных
Схема и данные Supabase не изменялись. Эта версия сайта пока не подключена к базе.
